# BitBloc — site estático

Versão em **HTML + CSS + JavaScript** (sem Next.js / Node obrigatório).

## Como abrir

1. Abra a pasta `bitbloc-site`
2. Clique duas vezes em `abrir.bat` **ou** em `index.html`

## Estrutura

| Arquivo | Função |
|---------|--------|
| `index.html` | Página |
| `css/styles.css` | Visual / layout |
| `js/data.js` | Produtos, FAQ, reviews |
| `js/app.js` | Filtros, modal, FAQ |
| `assets/` | Logos SVG |

Mesmo visual da versão anterior: hero, destaques, vitrine com busca/filtros, categorias, reviews, FAQ e newsletter.
